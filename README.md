# Currency Converter

## 📌 Overview
This project is a **Python-based application** designed to simplify currency conversion while visually representing the results.  
It uses **Tkinter** for the graphical user interface (GUI) and **Matplotlib** for displaying conversion results in a bar graph.  

The project was developed during my **Python Programming & Data Analysis course under the Code Unnati Program (SAP CSR initiative, implemented by Edunet Foundation)**.  
Later, it was also submitted as part of the **Code Unnati Innovation Marathon 2024–25**, where participants showcased innovative projects.

## 🛠️ Tech Stack
- **Language:** Python  
- **Libraries:** Tkinter | Matplotlib  
- **Tools:** VS Code | GitHub  

## 🚀 Features
- User-friendly GUI for currency conversion  
- Real-time conversion logic  
- Bar graph visualization of conversion results  
- Extendable for multiple currencies
